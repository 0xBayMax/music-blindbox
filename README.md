# 抽个 Beat 🎮🎵

> 抽 3 张盲盒卡，合成一段属于你的循环 Beat。

**[▶ 在线体验](https://traedemos.com/zh-CN/works/4480?from=%2Fprofile)**

---

## 产品背景

这是 [Trae 1024 程序员节](https://traedemos.com/) 的参赛 Demo。

比赛的报名方式是抽盲盒——作者现场抽到 3 张卡组成了这个题目。于是产品顺着这个梗做成了一台「音乐盲盒机」：

> **我们抽到什么，就做什么；你抽到什么，就听到什么。**

## 怎么玩

```
开机 → 按 Ⓐ 抽卡 → 3 张卡依次翻开 → 放入 节奏 / 和声 / 音色 三个卡槽
     → 自动合成循环 Beat → 任何时候换卡，音乐不中断、无缝切换
```

- **Ⓐ 键抽卡**，**Ⓑ 键重抽**，可锁定喜欢的卡只换其他的
- 抽到 **SSR** 有全屏金光 glitch，三槽同时 SSR 触发**隐藏曲目**
- 牌堆里混着 6 张程序员梗彩蛋卡（`rm -rf /`、`404 Not Found`、`sudo make beat`……），抽到即触发全局突变效果

## 42 张卡牌

| 卡槽 | 数量 | 控制什么 |
|---|---|---|
| 🥁 节奏 | 12 | BPM、鼓组 pattern、Swing |
| 🎹 和声 | 12 | 调式、和弦进行、Bass 走向 |
| 🎸 音色 | 12 | Lead 合成器、琶音模式 |
| 💀 彩蛋 | 6 | 全局突变（不占槽位） |

稀有度 N / R / SR / SSR，单次抽卡出 SSR 概率约 32%——多抽几次，金卡总会来的。

**彩蛋卡清单**（全是程序员梗）：

| 卡 | 效果 |
|---|---|
| `rm -rf /` | 静音当前一轨（再抽一张可恢复） |
| `Ctrl+C / Ctrl+V` | 复制某一轨的 pattern 到另一轨 |
| `404 Not Found` | 随机丢拍，鼓点"失踪"一小节 |
| `Hello, World` | 插入提示音切片作为采样 |
| `Stack Overflow` | 全局过载失真 + 音量暴涨 |
| `sudo make beat` | 全轨道音量拉满 + 金色滤镜 |

## 设计思路

**3 张卡怎么撑起一首 Beat？—— 每张卡不是一个音色，而是一组轨道的参数包。**

```
节奏卡 ──→ Kick + Snare + Hi-hat + Perc（自动伴随层）
和声卡 ──→ Bass + Chord Pad（自动 voicing）
音色卡 ──→ Lead + Arp（错开八度的琶音）
```

3 张卡驱动 **8 个声音层**——Kick / Snare / Hat / Perc / Bass / Pad / Lead / Arp，正是一首成品 Beat 的标准配置。再叠加：

- **母带链**：EQ → 压缩 → 限制器，发送混响 + PingPong 延迟，kick 侧链压缩 Bass/Pad 做出"呼吸感"
- **调性统一**：所有和声卡量化到 C 系调性，任意 3 卡组合都不翻车
- **无缝换轨**：新卡入槽写入 pending，下一小节边界自动切换，听感零断点
- **零素材**：全部参数化合成（Tone.js），零音频文件、零网络请求

**视觉**：复古卡带游戏机风——GB 掌机外壳、CRT 深绿屏、像素卡带贴纸、程序生成的像素卡面（按卡牌 id 做图案种子，零美术资源）。

## 技术栈

Vite + React + TypeScript + [Tone.js](https://tonejs.dev/)，纯静态构建，无后端。

```bash
npm install
npm run dev      # 本地开发
npm run build    # 构建 dist/
```
